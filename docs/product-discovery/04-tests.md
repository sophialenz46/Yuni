# Tests

## Aktueller Stand

Im Rahmen der Product Discovery wurde zunächst eine Online-Umfrage durchgeführt, um die Probleme, Bedürfnisse und Funktionswünsche der Zielgruppe zu identifizieren.

Die Ergebnisse wurden unter [Target Users + Problems](02-users-problems.md) dokumentiert.

## Geplante Tests

Im weiteren Entwicklungsverlauf sollen die geplanten Funktionen von Yuni anhand eines Prototyps überprüft werden.

Dabei soll insbesondere untersucht werden, ob Studierende:

- relevante studentische Gruppen einfach finden können,
- sich innerhalb der Plattform zurechtfinden,
- benötigte Studieninformationen schnell erreichen,
- die angebotenen Funktionen als hilfreich empfinden.
